## 📜 Current Scripts

### 🔧 Wireless Fixer & Reset Tool

A Bash script for resetting a wireless network interface and restarting NetworkManager on Linux.

**Features:**
- Checks for root privileges
- Resets the `wlan0` interface
- Sets the interface to Managed mode
- Restarts NetworkManager
- Displays status messages during execution

---

## ▶️ Usage

Make the script executable:

```bash
chmod +x wireless-fixer.sh
```

Run the script:

```bash
sudo ./wireless-fixer.sh
```

> ⚠️ Always understand a script before executing it, especially when it requires root privileges or modifies system settings.
